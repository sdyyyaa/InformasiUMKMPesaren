Koneksi Supabase

Hubungkan portal UMKM dengan database cloud

Petunjuk Penting:

1. Jalankan skrip SQL skema Supabase yang ada di dalam file implementation_plan.md pada SQL Editor Supabase Anda.

2. Salin URL Proyek & Anon Key Anda, lalu paste di bawah untuk menghubungkan web secara online.

3. Jika kolom di bawah kosong, web otomatis menggunakan mode offline (localStorage) demi kenyamanan testing.

Status Koneksi: Terputus (Mode Offline)
Database Terkoneksi
